# Support

Use [GitHub Issues](https://github.com/RockxyApp/RockxyGent/issues) for reproducible bugs and feature requests. Include the Rockxygent version and build, macOS version, guest Linux image or distribution, selected network mode, and steps using a disposable sample repository.

Remove credentials, private source code, private hostnames, account paths, agent console output with real data, and license details from text, screenshots, logs, VM exports, and attachments. For a vulnerability, follow [SECURITY.md](SECURITY.md) instead of filing a public issue.
