# Security

Use GitHub's **Report a vulnerability** flow on this repository's Security → Advisories page for a private report. Private vulnerability reporting was enabled and verified before the first public release. Do not open a public issue containing a vulnerability or secret.

Use a disposable project and test credentials for reproduction. Remove private source, agent output, VM disks, snapshots, access tokens, hostnames, account paths, and license details from reports and attachments. Supported versions will be identified after the first public release.
