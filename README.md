# RockxyGent

RockxyGent brings coding-agent work into a native Mac workspace: a local Linux VM, a reviewed copy of your project, and an explicit step to inspect and import changes. Its application source is kept in a private repository. This public repository is the home for issues, support, and release metadata.

## Availability

RockxyGent 0.1.0 is being prepared. The download and update feed will appear here after the signed release and its public assets are verified.

Use [Issues](https://github.com/RockxyApp/RockxyGent/issues) for reproducible bugs and feature requests. See [SUPPORT.md](SUPPORT.md) for safe report details and [SECURITY.md](SECURITY.md) for private vulnerability reporting.
