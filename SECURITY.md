# Security

Private vulnerability reporting must be enabled on this repository before its first public release. Until that is verified, do not open a public issue containing a vulnerability or secret. The release checklist will publish a working private reporting route before inviting security reports.

Use a disposable project and test credentials for reproduction. Remove private source, agent output, VM disks, snapshots, access tokens, hostnames, account paths, and license details from reports and attachments. Supported versions will be identified after the first public release.
