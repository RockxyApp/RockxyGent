# RockxyGent

RockxyGent is a proprietary macOS app for running coding agents in local Linux virtual machines and reviewing their changes before importing them into a project. Its application source is private. This repository is the public home for issues, support, and future release metadata.

## Availability

RockxyGent 0.1.0 is in development. There is no public download or update feed yet. A release will be linked here only after the distributable app and its public assets are verified.

Use [Issues](https://github.com/RockxyApp/RockxyGent/issues) for reproducible bugs and feature requests. See [SUPPORT.md](SUPPORT.md) for safe report details and [SECURITY.md](SECURITY.md) for private vulnerability reporting.
